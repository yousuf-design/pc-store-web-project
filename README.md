# PC Store Web Project 
## Overview 
PC Store is an academic web development project designed to showcase computer hardware products and accessories through a modern and user-friendly website. 

The project allows users to explore products, learn about available services, submit orders, and access support information through multiple interactive pages. 

## Features 

- Home Page 
- Products Page
- Order Form 
- FAQ Section
- Contact Page
- About Us Page
- Multimedia Integration 
- Responsive Design 


## Technologies Used 

- HTML5
- CSS3
- JavaScript

## Project Objectives

- Apply front-end web development concepts
- Design an interactive multipage website
- Improve user experience and navigation 
- Practice responsive web design principles
